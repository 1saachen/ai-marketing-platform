# 爆款复刻文档

固定流程：`上传素材 → 深度拆解 → 元素映射 → 成片生成`

新成片任务按对应原片片段生成每个镜头。深度拆解记录景别、构图、运镜和镜头内动作，元素映射绑定当前项目的商品图。镜头按原片切点和时长合成，逐镜对照同时间点的原片抽帧进行审片。当前支持 1–15 秒、最多四个镜头、720p 静音输出。既有任务按冻结快照恢复。[逐镜头视频参考](plans/2026-11-23-逐镜头视频参考上线.md)

同一项目 Run 内保存真实文件、六维报告、逐元素映射和确认工作副本。G2 支持采样画面分析与候选元数据建议，音频语义未评估。G3 支持抽帧审片、播放、下载和显式归档。配置规划模型后可按允许的场景变化生成三至二十条，先验证首条，整批完成后可下载 ZIP。运营环境已启用逐镜头视频参考，批量画面质量仍待验收。各环境默认关闭复刻入口。
