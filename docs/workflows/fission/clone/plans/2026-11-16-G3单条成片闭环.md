# G3 单条成片闭环

接续 [生成预检与媒体基线](2026-11-16-G3生成预检与媒体基线.md)。本期只发布单条、静音、硬切的受限路径。成片节点使用同一 Run 的已确认映射、报告和输入，按 ID、revision、哈希校验。入口显式确认预检合计供应商秒数。生成设置固定，由请求和执行记录保存。

| 环节       | 提交与恢复规则                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------- |
| 创建       | 在项目与 Run 锁内重新编译计划，创建 GENERATE Task、素材 hold 和独立队列 outbox。同一幂等键只对应原请求         |
| 渲染       | 每个镜头先持久化创建意图，拿到 ID 后只轮询该 ID。未知结果阻断重发。视频检查点通过同 Run FileObject + hold 保存 |
| 合成与审片 | 复用静音合成，服务端独立核验成片规格。审片按锁定镜头输出通过、证据不足或不通过及理由。后两种停止发布           |
| 提交       | 成片与批次工作副本、任务成功同事务提交。每次主动生成产生独立批次。上游变更使引用旧来源的产物待更新             |
| 交付       | 已提交视频可鉴权播放、下载及明确归档。归档用文件快照与稳定操作键去重。取消/失败不能发布结果                    |

沿用现有 G2 任务、步骤、文件 hold 与平台工作副本表。增量迁移扩展任务操作约束，支持 `GENERATE`。分析和生成消费者使用不同队列与独立 token。页面保持原型设置、进度、结果卡和预览层级，多条生成、局部返修和批量 ZIP 属于后续阶段。隔离验证使用显式模拟供应商和真实本地 FFmpeg。
