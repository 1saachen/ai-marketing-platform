# 爆款复刻原片编辑实施计划

日期 2026-11-20

## 范围

沿用上传素材、深度拆解、元素映射、成片生成四个节点。新成片任务默认用 Seedance 2.0 编辑授权原片。商品仍按确认规则替换，场景和邻近道具由用户选配，未选的视觉元素默认保留。已创建任务按冻结模式恢复，已交付成片保留原文件和版本引用。

已验证一个 4 秒实拍镜头内的单物体更换，首帧、运镜和手部动作基本对齐。多物体、有字包装、多镜头尚需真实验收。本轮先打通正式链路和离线验证，付费验收单独授权。

## 数据与提交

- 上传素材只要求参考视频与来源使用确认。商品名称、事实说明及补充素材按需填写。原片编辑依据映射确认的目标图替换，选中的商品和道具仍须绑定项目图片版本。
- 深度拆解仍消费同项目同 Run 的 `clone-input` 确认版本，成功提交流程沿用 `clone-analysis`。新增可选道具类型。每项用独立 ID、位置与外观描述、镜头区间及画面证据表示。模型提示词按任务冻结版本启用，已有报告可继续使用。
- 元素映射沿用 `clone-mapping` 和逐项保留／替换。新道具默认保留，替换时绑定当前项目图片的精确版本。界面显示出现的镜头，确认后才影响生成。历史报告补识别道具可重新拆解。
- 成片预检和创建消费三份确认工作副本的精确引用，冻结参考视频文件身份、目标图版本、目标对象描述、原始画面时间线、编辑模式和单条整段请求秒数。只给选中的对象编译修改指令。普通编辑保留现有草稿和 revision 语义；历史任务快照兼容原生成模式。
- 复用 Outbox、任务租约、供应商 ID、文件保活、审片和批次交付。每条变体最多创建一个供应商视频编辑任务。Worker 经受保护接口读原片和短期签名，签名不落库。已获任务 ID 时只续查。
- 供应商明确拒绝创建时使当前任务失败，允许用户调整输入后新建任务。网络中断或返回结果不明时保留创建意图和现有人工核查门禁，以防重复计费。
- 初版编辑覆盖 4–15 秒、最多四个源镜头、16:9 或 9:16、静音 720p。源片需满足供应商的 MP4/MOV、分辨率、时长、大小和帧率限制。短于 4 秒时预检提示更换片段，避免用拉伸帧或连续扩展冒充原片节奏。保留现有字幕、贴纸和音频能力边界。
- 供应商还会审核输入内容。含真实人脸的素材受方舟参考视频限制，批准的素材接入方式以供应商文档为准。[方舟视频生成 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)
- Seedance 输入原片、目标图和带镜头区间的定向编辑指令。使用原片完整上下文，一次完成同条的替换。合成按原片绝对帧区间取材。含替换的镜头取编辑结果，其他镜头直接取原片画面，输出总帧数与锁定时间线一致。
- 审片提供同时间点原片帧与成片帧，核对首帧、景别、运镜、手部接触、未选物件和目标对应关系。失败保留候选和审片细节。全部通过后沿用 `clone-video:<variantId>` 和 `clone-batch:<batchId>` 批次提交。当前项目已交付历史结果沿原版本访问。

## 验收

- 契约兼容性覆盖旧报告和旧任务，校验新道具默认保留及图像选择要求。API 测试覆盖确认源和文件保活、作用域、租约、费用确认和重试句柄。
- Worker 离线验证只向供应商创建一次，已知任务 ID 续查，合成复用未编辑镜头，首尾与时长同步，审片可读同时间点原片。
- 相关 Web、API、Contracts、Worker 测试及类型、构建、差异检查，验证映射操作和恢复。
- 真实验收使用同一实拍素材，同时明确替换主商品和一个道具，确认首帧、保留物件、手部遮挡和目标包装。多镜头、带字商品、长尾输入后续各自用独立样本验证。
