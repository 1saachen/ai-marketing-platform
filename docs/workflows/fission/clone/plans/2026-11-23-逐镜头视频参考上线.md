# 逐镜头视频参考上线

## 范围

裂变类爆款复刻的成片生成接入已验证的逐镜头视频参考。保留四个节点和完整拆解。每条新成片按锁定时间线分别生成各镜头，每次请求使用原片的对应片段和当前镜头目标。输出沿用 720p 静音硬切。局部元素替换使用原有独立工作流。

此前试片的两镜各 4 秒，验证了保留原场景时固定机位、横移跟拍和手部动作的跟随。上线验证使用隔离供应商替身。真实业务生成仍由用户主动发起。

## 数据与任务

- 预检和任务创建在同项目、同 Run 校验确认的 `clone-input`、`clone-analysis`、`clone-mapping` 精确引用和映射图片版本。生成数量由用户确认。新快照冻结 `SEEDANCE_2_0_SHOT_REFERENCE`、原片文件身份、分镜帧区间、对象描述、镜头动作、目标图和每镜参考帧数。
- Worker 校验原片哈希并归一化为 24 fps，按照锁定帧区间提取每镜。参考片不足 2 秒时延长该镜头末帧至 2 秒。供应商看到的片段只对应当前镜头，成片依照原有帧区间裁切和拼接。参考视频格式和最短时长见[方舟视频生成接口](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。
- 预检明确展示整批输入参考时长和输出请求时长。创建接口重验二者。旧页面提交的新请求需要重新预检。历史创建重放沿用各自冻结模式及原确认条件。
- 镜头参考复用受保护媒体上传、FileObject、任务文件保活和 `FILE:reference-N` 检查点。API 校验帧数、编码和当前任务作用域，在记录该镜头的供应商创建意图前签发短期私有 TOS 地址。地址只进入对应供应商请求。任务终结由现有清理流程释放参考文件。
- 新镜头只在尚未发起供应商创建时准备或重签参考。已有供应商任务号时续查。明确拒绝按既有失败处理，结果不明确时保留 `CREATE_PENDING`。旧逐镜头文字参考和原片编辑快照继续按原模式恢复。
- 审片把归一化原片与成片按锁定镜头首中末和动作证据时点配对。通过整批审片后原子提交 `clone-video:<variantId>` 和 `clone-batch:<batchId>`，按原有规则下载、归档和标记待更新。

## 验收与发布

- 验证精确裁切、短镜头补尾、输入计量、旧客户端确认、重复创建、镜头隔离、迟到租约、断点恢复、临时文件清理、单条与较大批次。隔离联调检查每次生成只有对应镜头的视频参考，审片看到相同时间点的两侧画面。
- 无数据库迁移。确认无活动任务及待投递积压，备份并同步发布兼容旧快照的 Worker、API 和 Web。核对实际运行镜像、Worker 消费者、正式入口预检及旧项目读取。保留回退版本。
