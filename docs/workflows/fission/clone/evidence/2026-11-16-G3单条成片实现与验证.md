# 2026-11-16 · G3 单条成片实现与验证

范围为同一爆款复刻 Run，从确认的元素映射到单条静音 MP4。验收使用独立 PostgreSQL 16、正式 Web 和 API、本地工作存储与 FFmpeg、生成 Worker 流程和本地模拟供应商。测试调度轮询隔离数据库中的排队任务。没有启动真实 RabbitMQ 消费或发送 Seedance、Ark 请求。

## 浏览器观察

- 预检确认两镜头、8 秒请求渲染时长。提交后刷新页面恢复同一任务，随后任务自动完成。[确认参数](browser/2026-11-16-g3/01-确认生成.jpg)
- 浏览器播放器加载了 3 秒、720×1280 的 MP4。下载事件返回 28,465 字节的文件。[预览](browser/2026-11-16-g3/02-成片预览.jpg)
- 模拟审片告警使第二个任务失败，首条成片仍可访问。隔离库记录一个成功、一个失败，两份生成节点工作副本和一份正式成片资产。重复归档请求仍只有一份资产。[审片阻断](browser/2026-11-16-g3/03-审片告警保留旧成片.jpg)
- 验收首次发现刷新会丢失“已保存”按钮状态。列表改为读取持久化归档回执后，在重建的隔离库重新生成、归档并刷新，按钮恢复“已保存”，数据库保留一个成片资产。[刷新后已保存](browser/2026-11-16-g3/04-刷新后已归档.jpg)
- 在 1920、1440 和 390 像素宽度检查成片页，任务区域和页面均无横向溢出。[390 像素宽](browser/2026-11-16-g3/05-成片窄屏.jpg)
