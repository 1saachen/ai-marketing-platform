# G2 深度拆解与元素映射实现验证

日期：2026-11-11。范围：[G2 实施计划](../plans/2026-11-11-G2拆解与映射实施.md)。本记录接续 [G1 验证](2026-11-11-G1真实输入实现与验证.md)，不替代历史记录，也不表示日常环境已部署。

## 实现结果

正式四节点工作流已接通输入 → 深度拆解 → 元素映射。报告、映射、任务、文件引用和 revision 使用同一项目/Run 与平台工作副本。成片生成仍未实现。

- 新增共享六维报告、逐元素映射、结构锁、任务和内部快照契约，发布 JSON Schema；Python 直接消费共享 schema。
- `ANALYZE` 完整成功后自动提交 `clone-analysis`。人工编辑隔离保存，显式保存更新确认版；取消不改变确认报告。人工与自动提交均复核原视频规格和当前视觉分析能力。
- `SMART_MATCH` 只更新映射草稿；草稿已变时保留人工编辑、生成待采用建议。采用仍不自动确认。`clone-mapping` 由用户明确确认，所有产品必须逐项替换，结构必须等于确认报告。
- `VALIDATE_KEEP_TEXT` 独立核对字幕原文与目标商品事实；证据绑定两份来源与映射内容哈希。确认映射不暗中调用模型。
- Task/Step/FileHold、Outbox、独立 Worker token、租约/attempt、检查点、取消/放弃/重试及过期恢复已实现。PAUSED 允许后台合法完成；旧来源、旧租约和旧请求被拒绝。
- 候选仅冻结最近最多 80 份项目资产版本元数据与版本实体身份，不提前复制全部文件；实际引用版本才准备当前 Run 文件。未引用暂存项可回收，草稿、确认内容、活动/可重试任务和待采用结果保持文件引用。
- 暂停携带所有已有节点草稿 revision；普通导航不推进确认版。新表引用接入项目删除与通用文件清理，开关关闭时保守保留复刻文件。

审查与浏览器发现并修复：人工报告规格遗漏、短租约心跳间隔、任务重放前多余资产 IO、暂存资产累积、取消编辑跨窗口覆盖，以及 PostgreSQL JSONB 键顺序导致的错误 stale 判断。前端内容比较忽略对象键序但保留数组业务顺序。

## 实际能力限制

真实 Provider 代码使用 Ark Responses 对 FFmpeg 有界采样帧做视觉分析。六维结构包含音频维度，但音频语义明确为 `UNASSESSED`，只有音轨存在性经过探测；没有语音转录、逐帧镜头检测、音乐/音效识别、原音轨保留、音色克隆或烧录内容可靠提取。人工编辑也不能越过这些能力限制。

智能匹配目前依据候选元数据，不声称理解了候选图像或给出真实视觉匹配评分。采样边界是视觉推断，不能保证短暂事件全部被观察。真实供应商理解质量、费用和大规模时延尚未验收。

## 隔离浏览器与 HTTP 联调

沿用用户已登录的 `http://127.0.0.1:5174/`，API 为 `127.0.0.1:3111`，数据库为 `clone_g1_browser_20261111`。新增迁移后共 53 个迁移；独立事务库 `clone_g2_verify_20261111` 同为 53 个。仅在确认隔离任务无活动时重启隔离 API；未迁移日常数据库，未重启 5173/3100 服务。

验收启动器位于忽略目录 `.tmp/clone-g1-browser-qa/`。它不载入真实队列消费者或模型 Provider；本地轮询仅模拟消息投递，调用正式 Python `process_task`，经受保护 HTTP claim、文件下载/SHA 校验、FFmpeg 抽帧、进度、检查点、完成/失败接口执行。**模型输出来自明确标记的 FakeProvider，报告和建议均注明隔离测试；没有真实模型或付费调用。** RabbitMQ 的实际投递未在这次浏览器联调中运行。

使用本地合成 3 秒、360×640 的色块参考视频及绿色方块商品图。项目 A 为“复刻G1隔离验收A”，项目 B 为独立空项目。实际观察：

1. 空报告只允许在确认输入后开始；正式页面没有自动加载样例。
2. 拆解排队、40% 处理中、刷新续轮询、成功自动确认均显示；取消保持旧确认报告。注入可重试失败后重试成功，同一任务 attemptCount 从 1 到 2。
3. 报告人工编辑取消及保存可用，保存推进确认 revision；纵向镜头、证据时间与音频未知原因均展示。
4. 不完整产品映射被服务端拒绝。项目图片精确第 1 版可绑定；全部产品完成后为 2/2，镜头影响仅显示所属镜头。
5. 智能匹配运行期间编辑目标描述，完成后显示“建议待采用”，人工文字未被覆盖；明确采用后只改草稿。无并发编辑的下一轮建议自动进入草稿。
6. 映射确认后进入第四节点的明确不可用提示；相同映射再次确认没有增长 revision。
7. 报告确认变化后，已确认映射变成“待更新 · 第 1 版”，旧内容保留；按新报告重置、匹配并确认后成为第 2 版。
8. 映射刷新恢复、退出自动保存和从项目中心恢复通过；项目 B 的报告与任务为空，没有显示 A 的内容。
9. 1440、1920、390 宽度完成检查；390 的报告和映射没有页面级横向溢出，节点条保留内部横向导航。最终页面没有 alert，最终浏览器 warn/error 日志为空。

最终只读数据库核对：同一 Run 的 `clone-input` revision 5、`clone-analysis` revision 4、`clone-mapping` revision 2 均为 CURRENT；映射引用输入 5 和报告 4。5 个隔离任务中 4 个成功、1 个取消，无活动任务。确认的映射版本与浏览器一致；未创建 G3 任务或成片。
