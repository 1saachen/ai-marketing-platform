在真实 PostgreSQL、RabbitMQ、Nest API、生成 Worker 和 Chrome 上提交 20 条静音硬切成片。测试使用已确认拆解和映射的本地副本。供应商请求由测试替身处理，渲染使用已有 MP4 测试素材。Worker 实际执行文件恢复、FFmpeg 合成与文件校验，本轮供应商费用为 0 元。

- Chrome 由正式成片页确认 20 条和 160 秒请求渲染时长。页面在父任务执行期间显示规划状态。数据库最终记录一个规划任务、二十个生成条目和二十一条已投递 Outbox 记录。
- Worker 分别取得规划草案与规划审查，完成 40 个镜头渲染步骤和 20 次单条审片步骤。所有条目通过后才发布 20 个第 1 版成片工作副本和批次清单。
- 390px 宽度刷新后，浏览器恢复原批次与下载链接。点击正式页面的下载入口得到 ZIP，验证 20 个不同成片工作副本的条目顺序、文件大小、SHA-256 和 ZIP CRC。另通过接口下载并核对一条 G3 旧清单格式的 ZIP。未登录、跨 Run 和不符版本请求均被拒绝。[390px 整批下载](browser/2026-11-17-g4/390px-整批下载.jpg)
