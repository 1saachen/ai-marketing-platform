# 爆款复刻 G1 真实输入实现与验证

日期：2026-11-11。范围：G1 输入契约、API/数据库、正式前端接入及共享文件清理。输入代码、隔离事务检查和隔离环境浏览器验收已完成，通过项仅限下述实际检查；不代表四节点真实生成完成或日常/生产环境部署。

## 实现范围

- 正式入口初始化/恢复项目内 `FISSION / FISSION_CLONE` Run，按项目、Run、节点隔离工作区。显式 Mock 独立加载，不向真实 Run 回填样例。
- 本地参考视频/商品文件先登记上传尝试，落磁盘临时区，校验文件签名/类型/大小、媒体尺寸/时长及 FFmpeg 可解码性，再存为当前 Run 的 FileObject。当前项目资产按精确版本复制，并保留来源资产 ID/版本。
- 输入草稿保存为 WorkflowNodeState，服务端规范化后校验引用及 expectedRevision。输入确认使用 expectedDraftRevision 和 expectedInputRevision；同内容不增版，两轮实际变化分别提交新的 `clone-input` revision。商品事实与原商品效果区分，来源使用确认须明确勾选。
- 项目→Run 锁串行化草稿、确认、上传完成和暂停。暂停恢复提升编辑 revision，暂停本身携带 expectedCloneDraftRevision；旧编辑请求不能暂停新编辑代次。上传重试旋转 attemptToken，迟到完成/失败不能污染新尝试。
- 可用上传关联为草稿文件保活，确认产物与正式资产引用继续保留；使用中的文件拒绝移除。活动上传阻断项目删除，过期上传不持续占用配额；孤儿清理及项目清理顺序识别新引用。
- 前端保存串行化、项目/Run 切换丢弃旧响应，裂变模块切换等待保存；资产入口根据目标 workflowSpace 恢复正确模块。

深度拆解、元素映射、成片生成、任务/批次 Worker、播放交付及成片归档未实现，正式模式关闭这些能力。G0 只落实输入部分，完整供应商能力矩阵、生成帧时间线、音画策略和任务恢复预算仍待实现/验证。

## 配置与迁移

`FISSION_CLONE_ENABLED` 默认 `false`。开启前须完成 `20261111120000_fission_clone_uploads` 迁移，并配置可执行的 `FISSION_CLONE_FFMPEG_PATH` / `FISSION_CLONE_FFPROBE_PATH`；留空时使用 PATH。工具缺失明确失败，不自动回退 Mock。

关闭开关时，既有后台清理和项目删除不查询新增表；已有复刻 Run 的项目保守阻断删除，需要启用相应清理能力后处理。新表只保存 FileObject ID，不新增 storageKey 列。

事务测试阶段向独立验证数据库 `clone_g1_verify_20261111` 应用全部 **52 个迁移**，含新增上传表。数据库测试使用显式 `FISSION_CLONE_DATABASE_TEST=1`，测试内清理范围限定为随机项目。该阶段结束后确认无连接并删除此库，清理临时下载及媒体调试文件，保留既有 FFmpeg 工具。后续浏览器阶段另建 `clone_g1_browser_20261111`，同样应用 52 个迁移；该库与验收服务保留供查看。未迁移日常业务库，未开启真实消费者或执行付费供应商任务。连接凭证不记录在文档。

## 浏览器验收补记

2026-11-11 使用可连接的内嵌浏览器完成正式 G1 页面验收。早先的浏览器连接故障已解除；连接恢复后发现日常 `localhost:5173` 代理的 `3100` 仍为旧 API 进程，复刻接口返回 404，日常数据库也没有新增迁移。这是运行版本未更新，不能以构建成功推断已经部署。

因此验收使用 `http://127.0.0.1:5174/` → `127.0.0.1:3111` 和独立数据库 `clone_g1_browser_20261111`。使用正式 Web 与编译后的 G1/平台模块、独立本地存储；用户亲自登录，没有复制会话。验收入口仅监听回环地址，未装载任务消费者，未重启日常 API。排查旧入口时通过 UI 新建了一个空项目“复刻G1浏览器验收-20261111”，未向该项目上传素材或生成内容；没有修改日常数据库结构。

测试文件由本地 FFmpeg 合成：3 秒、360×640 的 MP4，以及 400×400 的绿色 PNG；另用文本伪装 MP4 验证拒绝。正式资产选择所需的 2 份 fixture 由真实 `AssetService` / 本地存储服务预置在隔离项目 A，**不是通过 UI 创建**。视频资产 v2 仅改变测试元数据，文件与 v1 相同；浏览器实际选择 v2，商品图实际选择 v1。
