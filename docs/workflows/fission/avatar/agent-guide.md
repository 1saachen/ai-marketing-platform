# 裂变类·数字人口播工作流指南

固定流程：`选择形象 → 口播文案 → 唇形驱动 → 背景配置 → 渲染输出`

## 业务目标

使用当前项目中的数字人、音色、文案和场景配置生成音画同步的口播视频。

| 节点     | 作用                                 | 直接上游             | 主要工作副本   | 直接下游      |
| -------- | ------------------------------------ | -------------------- | -------------- | ------------- |
| 选择形象 | 选择数字人版本、服装、姿态和授权范围 | 当前项目资产         | 数字人绑定     | 口播文案      |
| 口播文案 | 导入、生成或编辑口播稿并确认时长     | 项目资料、数字人绑定 | 口播稿版本     | 唇形驱动      |
| 唇形驱动 | 选择音色、语速、情绪并生成同步任务   | 口播稿、音色资产     | 唇形与音轨任务 | 背景配置      |
| 背景配置 | 配置场景、字幕、画幅和品牌元素       | 同步结果、项目资产   | 背景合成方案   | 渲染输出      |
| 渲染输出 | 合成视频、校验同步并提供导出         | 背景方案、同步结果   | 数字人口播成片 | 项目归档/交付 |

## 固定规则

- 数字人、音色、场景和字幕样式必须保存具体资产版本和授权状态。
- 文案确认新 revision 后，唇形驱动结果待更新；只改背景不应让口播稿或音轨重新生成。
- 长视频音画同步误差目标不超过 0.1 秒；超标时阻断最终导出并允许重新对齐。
- 公共数字人不能被工作流直接引用，必须先导入当前项目。

## 当前实现

正式入口是「裂变类 → 数字人口播」。工作台沿用冻结原型的单页布局，包括数字人、音色、背景、文案、字幕、画面预览和三轨。通过服务端开关 `FISSION_AVATAR_ENABLED` 开放项目工作台，默认关闭。

目前已接通项目 Run、受授权的具体资产版本、形象与音色预览、手工编辑或 TXT 导入文案和服务端草稿恢复。用户点击「采用此形象」与「确认口播文案」分别提交工作副本，口播稿时长显示为估算值。音色选择保存在草稿，创建唇形任务时冻结选定版本与授权。项目退出前校验编辑 revision 和保存状态。形象、文案和同步素材可从项目资产库的工作副本列表返回工作台。

形象及音色授权由运维按项目资产版本登记。启用 `FISSION_AVATAR_SYNC_ENABLED` 后，用户点击「生成数字人口播视频」才创建任务。Worker 合成普通话语音并驱动已确认的单人视频，媒体结构、驱动音频一致性及来源授权通过校验后自动提交同步工作副本。工作台支持恢复任务状态、取消、重试及预览已提交的视频、音轨和字级时标。 [API 与授权登记](../../../../apps/api/src/workflows/fission/avatar/README.md)

背景与字幕共用一份独立草稿。确认方案时保存当前 `avatar-sync` 引用、背景、画面留边和字幕设置。背景可用纯色或当前项目的已可用图片，原视频等比放在竖屏画布中。人物前景抠像仍待验收。字幕以实际音轨时标为起点，可编辑时间和文字，可内嵌到成片或导出 SRT。已确认方案或同步结果变化后，实际依赖旧版本的成片标记待更新。

启用默认关闭的 `FISSION_AVATAR_RENDER_ENABLED` 后，底部「渲染成片」创建独立 FFmpeg 任务。口型测量报告须匹配候选成片摘要和已配置的校准方法。通过覆盖、置信度与 100 毫秒偏差校验后，工作台开放 1080×1920 MP4、所选 SRT 及项目归档。下载和归档均复核来源授权，同一成片 revision 的归档返回同一资产版本。 [渲染与评审配置](../../../development/local-development.md#数字人口播项目工作台)

G4 长片试点通过默认关闭的 `FISSION_AVATAR_LONG_ENABLED` 启用。用户在现有生成入口选择 61–90 秒长片，后台将已确认整稿按自然停顿冻结为 3–12 段，每段最多 60 字。各段使用相同的授权形象片段与音色版本，每段口播须落在形象片段时长内。工作台显示段序和已完成数量。续跑保留已完成分段及已受理的供应商任务，全部验证后提交同一类 `avatar-sync` 工作副本，并按实际时标渲染成长片。验收绑定最终 MP4 的摘要、片长、全部接缝及独立口型匹配准确率。 [长片隔离联调](evidence/2026-11-24-G4工作台长片链路验证.md) · [离线预检命令](../../../../scripts/fission-avatar/README.md#g4-离线长片预检)

启用默认关闭的 `FISSION_AVATAR_CONTINUITY_ENABLED` 后，同一长片入口为新任务使用尾帧接续。形象须在当前项目的有效授权版本登记同账号、可读取原始尾帧的方舟任务。Worker 先从整稿配音实测 5–12 个 4–15 秒的驱动区间，再按段用 Seedance 生成画面并对齐口型。首段取已登记任务的原始尾帧，后续段取上一段的原始尾帧。原始尾帧地址只在 Worker 内存传递。工作台在切片计划确定后显示段数。旧任务按其冻结输入继续，待续跑的分段通过保存的供应商回执和已校验媒体恢复。完整成功仍提交原有 `avatar-sync`，其下游继续按同步 revision 处理。 [尾帧样片](evidence/2026-11-24-Seedance尾帧接续对照预检.md) · [尾帧长片隔离联调](evidence/2026-11-24-G4尾帧接续长片验证.md)

Vite 开发预览入口为 `http://localhost:5173/fission-avatar-preview.html`。预览使用独立演示项目。形象返修、模拟音色试听、时间轴和 ZIP 导出使用浏览器演示数据。
