# 数字人口播 G2 同步素材接入与验证

2026-11-24，作用域为隔离 PostgreSQL、正式 Nest HTTP 入口和 Python Worker。工作台用已确认的形象和文案、授权音色版本创建异步任务。当前试点接受 1–30 秒、64 MiB 以内的单人 SDR MP4，以及最多 120 字的文案。 [实施计划](../plans/2026-11-24-数字人口播真实生产链路接入计划.md)

## 实测结果

- 隔离数据库应用 59 条迁移。HTTP 验证覆盖重复创建和回写、授权媒体分段读取、跨项目拒绝、草稿编辑不触发待更新、连续两次文案确认使旧结果待更新，以及取消后保留旧结果。
- 模拟 MediaKit 受理结果未知。使用错误操作令牌登记被拒绝。核对后登记成功且可重复提交。重试继续使用原语音和 MediaKit 任务 ID，旧 attempt 无法回写。
- 使用替身供应商、真实 FFmpeg 和 Python Worker 的任务处理入口，经内部 HTTP 领取并上传音轨、同步视频和字级时标。Nest 自动发布同步工作副本 revision 2，用户侧可鉴权预览。该验证直接调用 Worker 处理入口。
- 用已有 G0 素材复验媒体检查。形象片段 10000 毫秒，解码后驱动音轨 5592 毫秒，输出视频 5600 毫秒。采样区间内驱动音轨与成片音轨测得偏移 0 毫秒，最低波形相关系数 999‰。口型与发音的逐事件误差仍待测量。 [G0 与 G1 验证记录](2026-11-24-G0-G1验证.md)
- 契约测试 459 项、API 定向测试 82 项、Web 定向测试 40 项、Worker 测试 10 项通过。工作区类型检查、API 和 Web 构建、Worker mypy 与 Ruff 检查通过。开发和生产 Compose 配置解析通过。

## 验收边界

试点开关 `FISSION_AVATAR_SYNC_ENABLED` 默认关闭。本轮使用隔离数据库和替身供应商，未新增付费调用，未部署到日常环境。浏览器回归中途停止。Docker daemon 无法连接，镜像构建及 RabbitMQ 消费联调待验收。背景与字幕合成、最终下载与归档属于 G3，长片分段与口型误差校验按后续计划验收。 [开关与配置](../../../../development/local-development.md#数字人口播项目工作台)
