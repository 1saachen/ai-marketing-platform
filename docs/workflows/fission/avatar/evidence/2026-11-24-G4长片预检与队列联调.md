# 数字人口播 G4 长片预检与队列联调

2026-11-24，验证范围是本地长片预检和隔离短片渲染队列。现有工作台继续使用最长 30 秒的短片契约。本轮使用已有授权测试视频及合成夹具，未新增供应商调用。 [实施计划](../plans/2026-11-24-数字人口播真实生产链路接入计划.md)

## 长片预检

- 一份 UTF-8 测试稿按自然停顿拆为 11 段。计划按规范化稿件记录摘要和字符区间。测试覆盖中英混排、特殊字符、小数、分组数字、标点和无可用停顿。
- 复用同一条 G0 已驱动视频及原语音 11 次，在本机 FFmpeg 合成一条 61.600 秒有声音画候选。校验到 H.264/AAC、30 fps、1848 帧和 10 处实际接缝。31 个机械音频检查区间中，波形抽查最大偏移 0 毫秒、最低相关性 999‰。全片字级时间按段偏移，G0 测试字面使用占位文本。 [样片出处和许可](2026-11-24-G0-G1验证.md)
- 同清单复跑保持候选 SHA-256 和文件时间不变。三段内容不同的合成媒体测试中，末段注入故障后保留前两段检查点，只重做末段。清单、输入内容或检查点变化将阻断复用。
- 独立标注评分核对最终文件 SHA-256、FFprobe 实际时长和报告中的所有接缝。合成标注覆盖正负边界、累计漂移、缺测、低置信及发音单元匹配率。61.600 秒候选的实测时长和 10 处接缝与报告一致，缺少独立口型标注时返回待校验，未输出评审摘要。机械音轨偏移不作为口型偏差结果。 [预检与标注命令](../../../../../scripts/fission-avatar/README.md#g4-离线长片预检)

## 实际 RabbitMQ 链路

- 在回环端口启动便携 RabbitMQ 4.4.1 和 Erlang/OTP 27.3.4.19，验证官方文件摘要、AMQP publisher confirm、消费及健康检查。 [RabbitMQ 发行工件](https://github.com/rabbitmq/rabbitmq-server/releases/expanded_assets/v4.4.1) · [Erlang/OTP 发行说明](https://www.erlang.org/patches/OTP-27.3.4.19)
- 隔离 PostgreSQL 和正式 Nest HTTP 创建短片渲染任务，Outbox 收到实际 RabbitMQ 投递确认。以仅渲染模式启动日常 Python Worker，从真实队列领取、调用 FFmpeg、上传，工作台状态推进到待口型校验。
- 使用隔离测试口径验证摘要不符时拒绝、摘要匹配时进入已核验、MP4 和 SRT 可鉴权读取、重复归档回执，以及上一版工作副本和正式资产保持可读。该流程验证交付开关和材料的文件身份。

## 发布边界

长片预检当前运行在本地目录。接入正式长片仍需要逐段供应商任务、授权素材、实际发音与口型独立标注及校准。实际 RabbitMQ 联调验证了现有的短片渲染链路，生产容器和试点部署仍待验收。

分段、标注和评分共 18 项 Node 测试通过，Worker 16 项 pytest 通过，12 个 Python 模块通过 mypy。运行 `node --test` 的定向脚本、Worker 下的 `python -m pytest -q` 和 `python -m mypy src`，并检查 ESLint、Ruff、Prettier 和 Git 空白差异。
