# 数字人口播 G0 与 G1 验证记录

日期 2026-11-24。范围为本地隔离试点与公开资料核查。 [实施计划](../plans/2026-11-24-数字人口播真实生产链路接入计划.md)

## G0 供应商与同步测量

- 首选豆包异步 TTS 2.0 的预置普通话音色，以及火山 AI MediaKit 北京口型接口。语音任务提交前冻结调用方 ID，提交结果未知时按 ID 查询。口型接口接收单人 SDR MP4 和独立音频，并支持调用方任务令牌。小样对已知任务轮询，避免提交响应丢失后再次计费。 [豆包异步语音提交](https://docs.volcengine.com/docs/doubao-voice/task-sub-mission?lang=zh) · [豆包查询](https://docs.volcengine.com/docs/doubao-voice/result-query?lang=zh) · [MediaKit 视频口型对齐](https://docs.volcengine.com/docs/intelligent-processing/lip-sync?lang=zh)
- 小样脚本用本地私有目录保存任务标识、产物和恢复信息。真实运行范围为已授权的一条不超过 30 秒的单人 MP4 和最多 120 字文案。当前完成 FFprobe 本地预检、固定响应测试及未知提交结果恢复测试。生产能力、时间戳精度、真实嘴部同步和合成所需的前景处理仍待实测。 [小样运行说明](../../../../../scripts/fission-avatar/README.md)
- 人工时标工具覆盖首、中、末和接缝，按最大绝对误差与不确定度计算。正负 80、100、120 毫秒、尾段漂移、单个接缝错位及测量缺失均有离线断言。这些测试验证判定逻辑，生产自动检测仍需实际成片测量。 [人工时标测量](../../../../../scripts/fission-avatar/check-sync.mjs)
- 真实单条小样已完成。按本轮授权使用荷兰法证研究所发布的纯文生视频 `Sora_SYN/14.mp4`。原视频 10 秒，单人正面出镜。发布者采用 CC BY-SA 4.0，样片保留画面中的原标识，并在适配成片元数据和旁置署名文件记录出处、改动及许可。 [素材及署名](https://huggingface.co/datasets/NetherlandsForensicInstitute/synthetic-portrait-videos/blob/main/README.md) · [指定素材](https://huggingface.co/datasets/NetherlandsForensicInstitute/synthetic-portrait-videos/blob/53f07ed31127fa21c2bd7db4e043dd1770f9a921/fake/Sora_SYN/14.mp4) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

### 单条真实小样复验

- 豆包初次提交返回 `40000000`，按原操作标识查询确认未创建任务。按官方请求示例缩减参数后，同一标识提交成功。查询遇到本机代理 DNS 的 TLS 断连，单次运行改用公开 DNS 返回的同域 IPv4 地址，保留 HTTPS 主机名和证书校验，然后查询原任务继续执行。共一条被受理的语音任务和一条 MediaKit 口型任务。 [豆包提交接口](https://docs.volcengine.com/docs/doubao-voice/task-sub-mission?lang=zh)
- 语音长 5.592 秒，包含 27 条字级时间标记。MediaKit 成片长 5.600 秒，854×480，30 fps，视频 H.264、音轨 AAC，FFmpeg 全片解码通过。比对成片首、中、末三个窗口与驱动语音的解码波形，按 0.5 毫秒步长计算的最佳偏移均为 0 毫秒，相关系数至少 0.999。该数据验证成片使用相同的驱动语音。
- 抽查原片和处理结果后观察到口型变化。人工逐帧尚未获得完整可靠的声学事件与唇部事件配对，100 毫秒口型误差、前景可分离性、竖屏成片规格及长片接缝仍待验收。
