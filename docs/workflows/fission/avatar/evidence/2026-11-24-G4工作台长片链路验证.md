# 数字人口播 G4 工作台长片链路验证

2026-11-24，隔离 PostgreSQL 应用第 61 条迁移 `20261124130000_fission_avatar_segmented_sync`。在回环地址启动正式 Nest API、RabbitMQ 4.4.1 和 Python Worker 任务处理入口。供应商采用显式测试替身，使用合成语音波形与三段 21 秒 SDR 视频；生产 Worker 仍使用真实适配器。 [实施计划](../plans/2026-11-24-数字人口播真实生产链路接入计划.md)

## 分段生成与续跑

- 从正式 HTTP 入口确认形象、音色和整稿，选择长片规格触发一个任务。服务端冻结并拆为三段。重复提交相同幂等键返回同一任务，跨项目读取被拒绝。
- 第一段完成后在第二段唇形结果查询注入可重试故障。隔离 API 返回已完成 `1/3`、第 2 段失败。该阶段没有发布 `avatar-sync`。
- 重试沿用原任务和已完成的第一段，第二段查询原受理 ID 后继续第三段。三段各只有一次语音提交和一次唇形提交，第二段有两次结果查询。真实 FFmpeg 合成 **63.000 秒**的口播同步副本，接缝为 21.000 和 42.000 秒，音画可鉴权读取。
- API 定向数据库回归另外覆盖关闭开关、旧租约写回、未知供应商受理按段对账、字幕时标校验和中间文件清理。

## 渲染、评审与交付

- 确认背景和字幕后，真实长片渲染队列消费并生成 1080×1920 MP4 与 SRT。SRT 包含 `00:01:00,500 --> 00:01:01,800` 的字幕。
- 候选需使用独立评审凭据读取。实际候选摘要与时间线一致。缺少接缝证据或接缝不匹配时保持待核验。显式测试报告通过后，MP4 可分段读取和下载，SRT 可下载，并发归档只返回同一项目资产版本。
- 修改背景后只渲染新成片，口播任务和同步 revision 不变。评审 CLI 读取候选及时间线，缺少标注时评分暂缓。另以 101 毫秒测试证据验证拒绝发布，上一版仍然可读，资产回执不变。
