# 数字人口播 G4 尾帧接续长片验证

2026-11-24，在回环地址的隔离 PostgreSQL、正式 Nest API、RabbitMQ 4.4.1 和 Python Worker 中完成。隔离库应用第 62 条迁移 `20261124140000_fission_avatar_continuity`，启用尾帧接续开关。TTS、Seedance、MediaKit 使用显式测试替身，媒体解码、驱动切片、音画校验和成片渲染使用实际 FFmpeg。12 秒真实供应商样片单独记录。 [尾帧对照样片](2026-11-24-Seedance尾帧接续对照预检.md)

- 从正式工作台 HTTP 入口确认已登记原始任务的形象、整稿和音色。重复提交原幂等键返回同一任务。整稿配音一次，按停顿切出五个 13 秒片段。测试替身核对首段使用形象原始尾帧，后续按次序收到上一段原始尾帧。
- 第二段口型任务受理后注入一次结果查询故障。任务返回已完成 1 段，当前同步工作副本为空。重试沿用同一任务和已确认首段，按原受理 ID 取回第二段后继续。整条链路有 1 次配音提交、5 次画面提交及 5 次口型提交。
- 确认的同步媒体为 65.000 秒，保留 13、26、39、52 秒的接缝。生成了 1080×1920 成片候选，继续验证缺少接缝证据时禁止交付，显式测试评审通过后开放 MP4、SRT 与重复归档。成片评审口径仍为独立口型测量，隔离测试使用的结果仅对应测试媒体。

这次验证覆盖 65 秒任务的队列执行、续跑和交付边界。真实 61–90 秒供应商样片、实际口型准确率和生产启用需另行验收。
