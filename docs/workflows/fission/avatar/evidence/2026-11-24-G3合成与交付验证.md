# 数字人口播 G3 合成与交付验证

2026-11-24，验证使用克隆的隔离测试数据库、独立媒体目录、正式 Nest HTTP 路由和 Python Worker。历史 G0 短片只用于本地合成复验。 [实施计划](../plans/2026-11-24-数字人口播真实生产链路接入计划.md)

## 合成、提交和归档

- 隔离 PostgreSQL 应用第 60 条迁移。通过项目资产接口上传 PNG，选择具体版本，确认留边与内嵌加 SRT 字幕。相同方案重复确认保持原 revision，重复创建请求返回同一任务。
- Python Worker 通过内部 HTTP 领取任务，读取冻结的 G2 视频、音轨和背景图片，调用 FFmpeg 生成竖屏 H.264/AAC MP4 和 UTF-8 SRT。直接调用 Worker 处理入口，任务推进至待口型校验。
- 待校验时，用户下载与归档请求被拒绝。使用 Worker 凭据读候选也被拒绝。评审命令下载候选并复核 SHA-256，错误摘要被拒绝。使用与候选匹配的测试测量报告驱动 100 毫秒边界和 101 毫秒超标分支。超标保留上一次已发布成片。
- 通过测试校验后，MP4 支持分段读取和附件下载，SRT 内容与确认方案一致。两次并发归档返回同一项目资产版本。新成片通过校验后，历史 MP4 和归档回执保持可访问。撤销来源授权后，MP4、SRT、归档和项目资产媒体读取均被拒绝。跨项目替换路径被拒绝。
- 背景连续确认两轮，成片变为待更新，G2 同步工作副本 revision 和最近任务 ID 保持原值。

## 媒体复验

复用已有 G0 口播素材，生成 1080×1920 中文内嵌字幕 MP4 和 SRT。解码后驱动音轨 5592 毫秒，视频 5600 毫秒。驱动音轨与成片音轨采样偏移 0 毫秒，最低波形相关系数 999‰。该项检验处理前后的音轨一致性。实际发音与唇形动作的误差仍待独立校准和测量。 [G0 与 G1 验证记录](2026-11-24-G0-G1验证.md)
