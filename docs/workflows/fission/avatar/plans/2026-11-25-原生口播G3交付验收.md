# 原生口播 G3 交付验收

2026-11-25，原生口播按用户确认的原片验收结果交付。G3 合成背景和字幕，验证合成前后的视频帧时间与原音轨关系，验收通过后发布成片。实际发音与嘴型的时间偏差仍由独立测量得出。

## 工作副本和提交

- 背景与字幕草稿和确认方案继续使用 `avatar-composition`。方案引用当前项目、当前 Run 已提交的 `avatar-sync` 版本。编辑草稿与确认方案遵循原 revision 规则。
- 点击「渲染成片」时，原生模式要求操作者确认已验收原片。请求携带该原片的 `artifactId + revision`；服务端核对当前版本和授权，并随渲染任务冻结验收来源、文件摘要和方案引用。确认等待期间发生来源或方案变化时，重新发起确认。
- 渲染复用原片内封装的音轨。Worker 逐帧核对画面显示时间，验证音轨包内容、顺序与时间，复核成片画幅、时长和可解码性。报告绑定源文件和成片 SHA-256。时间变化超限或文件校验失败时，任务失败并保留已发布交付。
- API 核对任务租约、具体项目与 Run、当前来源、授权、方案和实际上传文件，校验通过后原子提交 `avatar-output`。MP4、SRT 和归档继续由已发布版本提供，沿用授权与幂等逻辑。已有待评审候选、独立配音口型和分段任务按各自的独立评审契约处理。

## 迁移、验证和发布

复用任务输入快照和工作副本 payload，原生渲染增量使用 v3 内部契约。已有 v1 和 v2 快照可读可重试。预计无需数据库迁移。

隔离环境复用已验收的 30 秒原片，覆盖拒绝缺少原片确认或错误版本的请求、合成前后同步验证、刷新恢复、MP4 与 SRT 下载、重复归档和跨项目拒绝。使用合成媒体覆盖错位、丢帧和音频内容变化。验证旧候选仍进入独立评审。

发布先检查目标队列和生产任务空闲，备份数据库，定向更新 G3 Worker、API 和 Web。单独启用 G3 并验证原测试项目的成片与归档；保留当前原生生成服务及数据库备份用于回退。本轮合成复用原片，费用范围不包含新模型调用。
