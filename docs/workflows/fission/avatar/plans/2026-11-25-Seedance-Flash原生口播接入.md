# Seedance 2.5 Flash 原生口播接入

2026-11-25，数字人口播优先接形象图与提示词直出。用户上传项目形象图片、确认所选形象和提示词、指定 4–30 整数秒，再用 Seedance 2.5 Flash 一次生成带人声的视频。采用模型 `doubao-seedance-2-5-flash-261115`、单张参考图、480p、竖屏和原生音轨。用有声视频实测复核人物、台词、动作和画幅。 [方舟模型与参数](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh) · [人像素材规则](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)

## 工作台与数据

- 继续使用「选择形象 → 口播文案 → 唇形驱动 → 背景配置 → 渲染输出」。复用项目资产导入和具体版本授权，形象图片上传后由现有授权流程核验。对方舟要求登记的肖像，授权记录绑定经核验的方舟人像资产，使用资产 ID 送生成。
- 原生模式在文案位置输入生成提示词，在现有生成区选择秒数。形象绑定和稿件的确认及 revision 沿用现有规则。新任务冻结当前形象与文案的 `artifactId + revision`、已授权的具体图片版本、模型和目标时长。启用原生开关后工作台优先选用该模式，已有任务恢复其实际模式。
- 统一复用 Avatar 同步任务、状态、租约、幂等和 `avatar-sync` 工作副本。专用消费者只需方舟凭据，提交意图和已受理任务 ID 通过内部接口保存。先登记再发起，重试查询原受理任务，受理未明进入对账。所有业务数据按项目和 Run 隔离。
- Worker 核验可解码的 MP4 和原生音轨，提取同源音频供工作台预览，字级时标暂为空。完整产物通过媒体校验后自动提交 `avatar-sync`。授权预览和生成原片下载入口同步开放。可用原有背景和手工字幕继续包装，正式交付和归档沿用渲染与审核边界。

## 发布与验收

数据库采用加法迁移，原生开关默认关闭。此前的小样、MediaKit 短片及尾帧长片继续按各自已冻结的请求与结果契约处理。短片直出首轮验收包括缺授权和错误项目拒绝、4 秒与 30 秒边界、包含音轨的可解码视频、一次提交和受理恢复、旧任务兼容、刷新后预览下载及旧结果待更新。隔离测试使用明确的供应商替身，独立申请真实样片费用后做实际效果验收。
