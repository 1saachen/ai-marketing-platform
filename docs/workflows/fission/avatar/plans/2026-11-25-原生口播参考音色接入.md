# 原生口播参考音色接入

2026-11-25，数字人口播的唇形驱动节点在原生形象图直出时提供一个可选项目音色。默认由模型自动配音。用户可试听并选择一段已授权用于方舟生成的项目 MP3 或 WAV。 [创建视频生成任务](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh) · [音色参考提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)

## 版本与交付

- 原生音色选择沿用 `AVATAR_WORKSPACE` 草稿，单独记录 `nativeVoice`。创建任务时校验草稿 revision、已确认形象和提示词 revision，冻结所选项目音色的资产版本、授权与存储对象。旧草稿和任务按模型自动配音读取。配音改口型继续使用其音色选择。
- 在项目音色资产的现有授权中明确登记方舟参考能力。Worker 经内部文件接口读取冻结音频，校验实际容器、内容及 2–30 秒时长，随形象和当前提示词一次提交 Seedance。音频参考用于声线，当前提示词提供本次台词。
- 完整口播仍提交 `avatar-sync`。带音色的产物保存所用版本和授权，供改选音色时判断当前性，以及在预览、G3 渲染、下载和归档时复核权限。已受理任务按原供应商编号继续。

## 发布与检查

通过加法迁移为现有授权加入默认关闭的参考能力。发布时先应用迁移并同步 API、Web、Worker 与共用契约，再登记可送往方舟的音色版本。按本次要求只做静态检查，真实音色相似度及台词表现留待后续样片确认。
