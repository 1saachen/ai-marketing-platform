# 定制类局部更新与资产上传替换

## 已确认范围

完善现有五节点，按节点主动更新，保留人工成果与未受影响视频。不做整片合成、裂变类、公共资产和权限扩展；不自动调用付费服务。

## 更新与提交

- 资料变化：基于新资料提炼信息卡，保留人工修正，人工确认。
- 信息卡变化：AI 定向修改当前脚本，对比、编辑后人工保存。
- 脚本变化：更新关联资产、分镜和衔接；稳定对象/镜头身份，未改内容保持不变。
- 图片变化：保留分镜和有效提示词，只使实际使用图片的视频待更新。
- 提示词变化：更新对应视频。纯删除机械处理，有引用冲突先解决。
- 每个受影响节点提供黄色局部更新入口，先预览差异、范围、阻断和调用类型，再由用户执行。
- 更新限当前路径；兄弟分支不自动改写。失败保留旧内容与成功检查点，同内容不增业务 revision。

## 图片替换

现有单资产图片窗口增加上传/替换，支持 PNG/JPG/WebP、不超过 10 MB。先绑定草稿，保存修改后提交，取消恢复旧绑定；同内容上传复用。附属对象使用已有父级图片归属，不增加另一套绑定。

## 实现

共享契约提供更新预览和可选版本化局部任务输入。API 重新核对预览指纹、基线 revision、来源及项目/Run；复用现有任务、Outbox、Worker、检查点和工作副本。候选审校、人工字段保护和旧 attempt 回调保护贯穿执行及提交。图片来源同步必须证明内容未变。新字段使用可选 JSON 扩展，不新增数据库表；旧任务按原策略恢复，缺基线明确要求本节点重生成。

## 顺序与验证

1. 差异与依赖预览。
2. 图片上传替换、保存、取消。
3. 信息卡与脚本定向更新。
4. 资产、分镜、提示词和视频联动及恢复。
5. 单测、数据库集成、Worker 测试、类型/语法、构建与浏览器回归。

覆盖两轮来源变化、重复更新、同内容不增 revision、刷新、失败后恢复、分支隔离、迟到回调、非法图片和过期版本。执行 pnpm typecheck、pnpm build 和 git diff --check。真实付费测试单独授权；服务仅无活动任务时更新并核实生效。

2026-11-10 视频制作批次反馈。分镜、提示词和视频仍按依赖顺序确认。进度显示本批已完成、失败和待处理数量，结束后保留结果与下一步的范围入口。提示词及视频的失败项可在页头确认后批量继续，沿用原任务和检查点。API 按项目、当前路径、批次、目标和失败版本校验，视频接单结果未知时保留原因并停止继续。沿用现有任务和出站消息事务。验证部分成功、失败后继续、重复请求、过期来源、刷新恢复和下一阶段范围入口。

2026-11-09 修复分镜局部更新继续时反复读取同一份无效引用。仅在候选使用当前冻结原句的完整全文坐标时，Worker 将其换算为句内坐标，再校验原文、时长和实际修改范围。可继续使用已有候选进入审校。局部更新通过校验后，在任务完成事务内沿用现有分镜确认逻辑，刷新后可直接更新提示词。无法机械修正或审校仍有问题时，保留已有分镜并提示重新查看局部更新范围。用本地任务回放、受控审校及事务回滚验证。

同日补充分镜审校恢复。审校可精确引用实际的时长政策及能力配置。镜头时长安排原样沿用时，依据参考值或依据参考值与全部镜头时长得出的总时长差异作为提示，并保留原审校。固定时长、具体镜头容量与对白时间窗的问题仍按原规则校验。当前路径的来源、工作副本、范围和策略均匹配时，可复用最近一份已通过分镜校验的旧审校检查点，修复前的失败记录可直接核对已保存的候选。页面显示当前步骤、从任务创建起的用时和重试轮次。验证现有失败记录、重复恢复、真实容量问题与来源冲突。
