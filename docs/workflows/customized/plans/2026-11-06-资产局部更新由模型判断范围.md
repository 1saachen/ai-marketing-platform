# 资产局部更新由模型判断范围

按用户确认：定制类资产准备在脚本小幅修改后，由语言模型判断需要修改的资产和字段，其他资产原样保留，不按关键词或字符串相似度判断语义。

直接上游为当前路径已确认脚本、信息卡及它们的 artifactId/revision；基线为现有资产目录及节点草稿。沿用 ASSETS 任务、Outbox、租约和检查点，成功自动原位提交 `customized-asset-catalog` 与 `customized-object:<id>`，未完成不提交。下游仍按实际对象及内容变化判断分镜、提示词、视频是否待更新。

1. 新 ASSETS 局部任务冻结可选判断策略版本；历史任务保持原执行策略，不迁移旧任务、不新增表。
2. 既有对象识别步骤输出每项保留/需改字段及理由，只为必要新增对象创建定义。对已有对象仅提交指定字段补丁；独立审核完整候选，机械校验身份、人工字段、图片和范围。不能可靠判断或与人工字段冲突时说明问题并保留原结果。
3. 模型判断和补丁先保存检查点，刷新/失败后复用有效结果。不增加自动付费重试循环，真实生成只由用户明确触发。
4. 预览明确“待核对”不等于“全部修改”；执行后从真实检查点展示判断结果和原因。零修改允许只同步已核对来源，同内容不增加 revision，图片不自动重做。
5. 验证小幅改色只动产品、仅改台词无需重做定义、必要新增、人工冲突、越界拒绝、失败恢复、两轮来源、分支隔离和同内容 revision。执行 Contracts/API/Web/Worker 相关测试、类型与构建、浏览器桌面及窄屏，空闲后更新本地 API 和资产 Worker。默认无付费验证，不部署线上。
