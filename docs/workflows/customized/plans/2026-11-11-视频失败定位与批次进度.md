# 定制类视频失败定位与批次进度

## 范围

视频制作节点支持从失败批次定位分镜、预览该任务固定版本的参考图，并进入对应资产的图片制作窗口。逐镜重新生成成功后，原批次展示当前处理进度。

## 现有边界

- 上游为当前路径已确认的脚本、信息卡、资产目录、分镜和逐镜提示词，任务冻结实际消费的 artifactId、revision 和指纹。
- 资产图片先保存草稿，明确保存修改后确认。视频通过文件和来源校验后自动原位提交 `customized-clip-video:<clipId>`。
- 换图复用现有归属解析、资产编辑入口和更新范围预览。生成由用户触发。
- 页面复用 `CustomizedProductionWorkspace.vue`、`ProductionAssetVisual.vue` 和 `WorkflowInformationDialog.vue` 的布局与预览能力。

## 接口与数据

- `ProductionTask` 增加可选的只读参考图记录，仅返回对象名称、固定项目资产 ID 和文件版本。
- `ProductionWorkspace` 增加可选的局部媒体批次投影。批次目标固定，服务端按同项目、同 Run、同操作、同分镜核对后续任务。
- 后续成功任务需与当前有效成果相符，才用于完成旧失败项。排队和运行状态取真实任务，旧任务和检查点保留。
- 查询补齐最近批次及其后续记录，使刷新和超过近期任务列表上限后的显示一致。新字段沿用可选扩展，使用现有任务和产物表。

## 交互

- 失败区按分镜列出原因，提供查看分镜及固定参考图的操作。
- 参考图可打开当前所属主体的图片制作窗口，已删除或变更归属的对象显示实际情况。
- 人像审核按平台已有信息展示原因，任务引用的图片作为核对范围。
- 单镜重生成的排队、执行和成功会同步批次进度，成功成果采用情况由服务端核对。

## 验证

- 契约、API 和 Web 覆盖多人共用图片、旧图版本、删除对象、超出近期记录上限及跨项目和分支隔离。
- 批次覆盖单镜恢复、相同视频文件复用、较早成功及过期成果、部分失败、刷新、运行中和迟到响应。
- 数据库测试使用随机隔离项目并关闭任务出站。浏览器覆盖桌面、窄屏、失败检查、图片预览、生成完成及刷新。
- 执行相关单测、数据库集成、`pnpm typecheck`、`pnpm build` 和 `git diff --check`。本地服务在任务空闲时更新并核对生效。
