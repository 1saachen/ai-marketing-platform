# 资产局部更新由模型判断范围

日期：2026-11-06。作用域：本地定制类资产局部更新，未部署线上代码、未执行真实付费模型或图片生成。

## 实现与边界

旧局部路径虽然让模型保留无关资产，但仍把整份识别目录送去分类定义生成；全部对象又依赖整份脚本，因此小幅修改会显示并处理过大范围。

新 ASSETS 局部任务冻结可选版本，在既有 INVENTORY/IDENTITY 步骤判断逐项范围并定向修改已有资产，分类定义只处理必要新增对象。共享模型及 Schema 表达每项准确身份、需改字段与普通语言理由；字段为空可全部保留。引用失效由模型选择准确新引用，不以字符串相似度判断业务影响；代码只验证原文确实存在、身份、字段、人工保护及未改范围相等。

已有对象不删除、不换身份或图片。候选仍经过独立完整审校；范围外的新必要问题、人工冲突或无法可靠判断时保留旧内容并说明下一步，不能为通过审核自动扩大为全目录修改。新旧来源及草稿、租约、项目/Run 校验沿用既有机制。

API 在自动提交前再次核对范围；新局部结果经过完整校验后直接保留原有编辑元数据，不经整批整理的合并逻辑补入额外字段。原样内容使用现有不增 revision 的来源同步。仅原文引用改变的候选，与视觉定义修改分开展示为“仅同步依据”；这个展示分类使用实际候选与基线精确比较，不承担语义判断。

## 已执行验证

- 资产 Worker 受控全套测试 62 项通过。新增覆盖：改色仅更新产品必要字段、台词变化零定义生成、必要新增只定义新道具、保存判断后失败继续、人工冲突、跨对象补丁拒绝、独立审核不得扩大范围、引用失效一次机械校正预算及仅更新引用保留全部视觉属性。
- 共享资产模块及局部范围模块的严格 `mypy` 检查通过。生产 Worker 受控全套 138 项通过，确认共享底座未影响原视频路径。
- Contracts 相关三个文件 18 项通过，包括范围字段合法性、历史资产与原拓扑兼容；Python Schema 与共用快照一致。
- 定制类 Web 38 个文件、270 项通过；新增判断展示组件进一步定向执行通过。浏览器使用实际组件的显式隔离页，观察模型判断及理由，1920/1440/390 下预览无横向溢出，错误、阻断按钮禁用和无更新范围显示正确。没有借隔离页调用真实模型或写业务数据。
- API 相关七个文件 21 项通过，显式启用本地生产数据库测试。新隔离事务覆盖两轮来源、重复任务幂等、当前路径原位提交、无关对象版本不增、第二轮零修改产品版本不增、范围外候选拒绝、迟到完成不覆盖新结果、兄弟路径保留；事务回滚，任务不对消费者可见。
- 同时回归整批整理分支：发现之前冻结来源修复将父路径来源直接用于新分支提交而产生依赖冲突，修正为仅原位提交使用冻结来源，新分支使用其继承快照；分支数据库回归通过。旧来源测试的清理补齐先删除测试依赖，避免随机测试项目的级联外键清理失败；重跑通过。
- `pnpm typecheck`、`pnpm build` 通过，构建仍有既有分块体积及插件耗时提示。相关 ESLint、Prettier 和 `git diff --check` 通过。

这些受控结果不代表真实模型对所有小幅修改都能准确选范围；本轮没有执行付费端到端质量验证，也没有自动改写用户原有失败任务。
