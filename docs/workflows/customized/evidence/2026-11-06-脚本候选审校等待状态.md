# 脚本候选审校等待状态

日期：2026-11-06。范围：本地定制类脚本局部更新候选的状态展示，不部署线上代码、不重试生成。

## 实现

在 `ScriptLocalUpdate.vue` 复用现有 `/tasks/:id` 只读接口，按候选的准确任务 ID 查询排队、步骤和时间。状态展示使用定制类内部组件 `ScriptUpdateStatus.vue`，同时服务本方案状态区及候选窗口，不增加工作流节点或另一套任务状态。

- 展示读取依据、定向改稿、审校更新稿、准备候选的真实步骤；任务成功时提示可保存，失败/取消时明确保留原脚本。
- 审校中按钮说明“审校中，完成后可保存”，关闭按钮说明“关闭，后台继续”；成功后自动恢复“保存修改”。
- 已等待时间从任务创建时间计算，刷新后仍可从同一服务端时间恢复；剩余时间无法准确估计时如实说明。
- 进度查询失败显示未同步并重查；不重复发起生成。旧查询不能覆盖新查询或其他作用域。
- 同一任务轮询完成及关闭再打开保留人工候选修改，任务身份变化时禁止把旧输入保存到新候选。未确认内容、原脚本、业务 revision 与下游提交边界不变。

- 对本地已有已完成任务执行登录后的只读 HTTP 查询，验证任务时间为明确 UTC、四个步骤全部成功；没有调用生成或采用候选。

浏览器使用显式隔离页 `apps/web/tests/browser/customized-update.html`，请求由受控响应接管。实际检查 1920、1440、390 宽度：状态卡、步骤、已等待时间及保存禁用原因可读，弹窗无横向溢出，窄屏按钮可换行。

在受控审校状态中修改候选正文，任务自动变为完成后，保存按钮在原窗口自动解锁，人工正文保留。失败候选显示原因并保持保存禁用。以上仅验证组件和状态联动，不代表真实生成质量验收；本轮没有新增付费模型调用。
